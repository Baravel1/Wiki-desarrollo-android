# Wiki-desarrollo-android
Wiki: Desarrollo de Aplicaciones Móviles Android

Este repositorio contiene una wiki académica sobre el desarrollo de aplicaciones móviles Android, elaborada como parte del módulo de formación en tecnologías móviles. El contenido está dividido en secciones temáticas que abordan desde los fundamentos técnicos hasta el análisis estratégico del ecosistema de apps.

---

## 🧩 Contenido

### Parte I: Fundamentos del desarrollo móvil
- ¿Qué es Android y cuál fue el objetivo de Google?
- Tipos de plataformas de desarrollo (nativas, multiplataforma, low-code)
- Herramientas y componentes actuales (Android Studio, Firebase, Material Design)

### Parte II: Evolución de Android
- Diferencias clave entre versiones históricas
- Ventajas de Android 16 en el ecosistema actual

### Parte III: Innovación y nube
- Rol de la innovación en apps móviles
- Herramientas en la nube (Firebase, Google Cloud, AWS)
- Aplicación de estas herramientas a problemas empresariales

### Parte IV: MIT App Inventor
- Beneficios en entornos escolares y prototipado rápido
- Comparación con plataformas profesionales

### Parte V: GitHub en el desarrollo móvil
- ¿Qué es GitHub y cómo se usa?
- Valor agregado para empresas y equipos de desarrollo
